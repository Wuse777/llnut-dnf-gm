# 窄屏邮件与角色操作体验优化（2026-11-06）

## 范围和发布边界

按[上一轮UI评估](UI-UX-STATUS-20261106.md)落实非素材类问题：缩短手机邮件路径、压缩最近目标、收起角色次要操作、分层说明。保留CPAMC主题；缺失客户端素材仍按用户安排暂缓。本批只有前端、相关测试和文档，没有后端接口、数据库迁移、奖励规则、权限或维护流程变更。

**本批交付为仓库源码更新，不是生产发布。** 线上仍以原运行包 `20261106-comparison-a201f26` 为准；不能因为GitHub更新或本地构建通过就说线上界面已切换。未来部署使用既有版本化流程，不需要恢复素材才能发布本批交互优化。

## 已实现

- 邮件页先显示收件人；最近／常用目标改为默认收起的紧凑区，选中目标后自动收起，保留当前身份及收藏、分页、错误与重试能力。
- 1150px及以下将长串行工作区改为“选择物品／奖励与预览”切换，默认进入奖励草稿；固定切换栏显示数量、金币与账号货币提示。桌面宽屏仍为左右双栏。切换只改变展示，不卸载输入，不请求预览／确认或清空草稿。
- 草稿顶部“添加物品”直接切到选物并定位切换栏，键盘焦点返回已选按钮；加入物品保留选物状态，清单计数即时更新。
- 手机选物结果改为卡片排列，名称、编号、状态与加入按钮可同时查看，不再必须横向滚动到行尾操作。
- 邮件标题／正文改为可选展开区；投递规则、模板和游戏内边界放入可展开说明。必填原因与错误、金币10亿上限及大额领取提醒仍直接显示。
- 验证出错时自动切回草稿；标题／正文错误自动展开对应区域，再滚动并聚焦具体错误字段，避免隐藏提示。
- 角色详情只直接显示账号余额和发奖励两个主要操作；解锁、封禁及解封放入“更多操作”，原目标、删除标记及未决操作限制保持。在线状态提醒保留，技术说明分层折叠。
- 弹窗焦点范围包括展开控件本身，排除已收起区域中的按钮，避免键盘焦点落入不可见操作。

数量范围仍为1–2,147,483,647、邮件金币最多10亿；预览确认、幂等、审计和维护保护不变。没有用简化界面绕过业务校验。

## 最小验证

仅运行5份相关前端文件，共43项（邮件金币／校验、快捷目标、角色详情、工作区切换、弹窗键盘），并完成类型检查和生产构建。没有全量回归、后端测试或生产写入。构建仍提示JS单块超过500kB，本批没有冒充完成代码拆分或性能专项。

使用当前源代码运行本地合成API预览，未连接生产数据库；桌面1280px、手机390px检查：

- 默认邮件页收件人标题约250px，生成预览按钮约1788px，默认页高约2093px；选物表有50条合成结果但不再挤在草稿之前。上轮线上观察约6742px，数据环境不同，不作为严格同样本性能基准。
- 切换选物／草稿保留道具；滚动长选物列表时切换栏可见；手机卡片与桌面双栏均正常，未见整页横向溢出。
- “添加物品”后焦点在选物切换按钮；遗漏操作原因时回到草稿并聚焦原因输入，错误在字段旁显示，不发起业务预览。
- 手机角色默认仅两个主要快捷按钮，“更多”初始收起；首屏可见金币与等级卡片。本次使用占位头像，不以此证明真实素材覆盖。
- 浏览器未见JS错误。截图保留在维护电脑输出目录，不把浏览器会话或生产玩家截图提交到仓库。
