# DXT离线图片解码（2026-11-06）

## 实现

在已有IMG v2/v4读取器中增加DXT1／DXT3／DXT5标准块解码，覆盖zlib及声明长度正确的raw载荷、透明像素、显式Alpha、两种Alpha插值、边缘块裁剪、画布偏移和链接帧。raw声明长度不符、palette/DXT混合及未适配压缩保持unsupported，不猜测偏移或输出错误图。Microsoft官方BC格式文档和已有NPK格式常量是独立实现依据，参考见第三方说明。

不增加运行依赖或游戏素材；网页运行时不导入离线解码器，没有新的权限开关、数据库授权、迁移或后台解析任务。不修改道具数量、金币上限或已安装图片包。

## 最小验证

两个图片相关文件49项检查，包含新增DXT标准向量与合成NPK→IMG→PNG包、原格式/调色板/安全边界和运行时不导入离线模块检查；只运行这两个相关文件，不做全量回归。没有前端修改，不重复前端全量测试。

这些是人工构造的无版权游戏数据夹具，不是真实物品图片，不将通过的解码测试当作真实素材覆盖提升。真实匹配客户端NPK尚未取得，线上物品图标缺口仍在。
