# 统一物品卡片与手机详情抽屉

v0.5.0 新增部位、原始 PVF 品级、等级上下界与排序的组合筛选；可按 PVF 版本在本浏览器保存最多 12 组条件，并选择最多四件物品对比部位、等级、耐久和 PVF 基础定义值。批量策略对整个筛选结果生效，预览与确认使用同一组条件。对比不计算强化、技能或战斗总伤害。

当前源码包含统一卡片、手机详情抽屉、组合筛选和装备对比；装备语义见[装备编辑器](EQUIPMENT-EDITOR.md)。2026-11-08 已取得匹配客户端素材，66,456 项物品中 66,450 项可解析为图标，另有 11 个基础职业默认站姿；剩余缺口保留明确状态。原始素材与提取图片只用于私有部署，不进入开源仓库。当前实现、验证及部署结果见[本批报告](reports/DEVELOPMENT-20261109.md)，早期布局评估保留在[历史报告](reports/UI-UX-STATUS-20261106.md)。

邮件页窄屏工作区切换及手机选物结果卡片使名称与加入按钮无需横向来回滚动；选择详情仍不自动发放。交互设计与当时验证见[紧凑工作流报告](reports/COMPACT-WORKFLOWS-20261106.md)，新版部署状态以本批记录为准。

- 物品索引、邮件选物、附件草稿、礼包编辑/列表、礼包选物、操作预览和常用物品复用 `ItemCard`，显示图片/占位、编号、名称、类型及等级；点击名称查看详情，不会加入清单或调用发放接口。
- `ItemFacts`区分索引信息和角色存档：只展示已提供的字段；缺少品级名称时显示未收录，不把原始品级数字猜成史诗等名称。投递方式缺失时显示未知，不默认可堆叠。
- 桌面格子视图保留右侧详情；680px及以下使用贴底抽屉，可滚动内容和固定底部操作区，保留安全区。列表视图继续可用。
- 手机抽屉通过Teleport移出角色窗口，不被父窗口滚动区裁切；Escape、Tab/Shift+Tab归最上层对话框，关闭后返回原物品按钮，不误关闭底下角色或确认窗口。
- 切换容器、筛选和页码后关闭旧详情；视口跨断点时切换相应详情布局。
- 原CPAMC主题变量、浅色/深色和减少动态效果设置继续适用；不引入第三方字体、CDN、图片上传或新后端服务。
- 图片仅接受当前鉴权接口的精确PVF/SHA路径，缺失或失败使用占位。匹配客户端素材已完成离线解析；安装状态、实际装扮和游戏客户端视觉验收分别核对，默认站姿不代表完整纸娃娃。

自动化按改动选择相关组件测试，不要求每批全量运行；真实浏览器合成流程：构建后运行 `tools/browser-item-cards.mjs`（可通过PLAYWRIGHT_MODULE、CHROME_EXECUTABLE指定本机依赖）。后者自建回环静态服务、拦截全部API，验证无写请求、手机底部对齐、嵌套焦点与Escape、断点切换、无横向溢出。它不连接游戏服务器，不证明真实素材或游戏效果。
