# v0.6.3 · 修复图标与留白，优化加载并加入场景背景

发布日期：2026-11-09。

截图中导航和顶部工具栏的大块空白来自 Iconify 运行时依赖公共 API；生产 CSP 只允许同源连接，因此动态图标始终无法显示。改用固定图标数据的离线组件，构建时只收集源码实际引用的图标，不再访问图标 CDN。最近目标文字偏到卡片中间是旧按钮的 `justify-content:center` 作用于网格布局，现显式恢复左对齐。工作台横幅增加奖励、问题与维护入口。

新增原创天空城场景背景，桌面 WebP 约 287 KB，手机约 107 KB。登录表单保持不透明，工作台文字区加遮罩。生成方式及完整提示词见[背景说明](../design/BACKGROUND-ART.md)；它不是官方 DNF 壁纸或客户端提取文件。新[界面截图](../SCREENSHOTS.md)来自实际浏览器和本地合成 API。

加载改进：认证方法与会话检查并行，首页统计只由所属页面触发并合并在飞读取；后台刷新不再占用全局操作锁。最近访问记录在后台保存，并隔离旧会话响应。全局弹窗、选物、结果和主题设置按需加载。主入口仍较大，本次不声称已完成全部性能优化，也不将代码体积减少等同于交互耗时下降。

公开 `assets/` 下真实存在且带内容指纹的构建文件使用 `public, max-age=31536000, immutable`；仅公开 JS／CSS 使用 gzip。HTML、业务接口、鉴权图片、缺失资源和错误响应继续 `no-store`。CSP、nonce、Cookie、CSRF、预览、重新认证和幂等提交协议保持生效。

针对性验证：33 项后端策略测试、15 项工作区测试、2 项离线图标测试、2 项 nonce 测试，类型检查和生产构建；在生产同款 CSP 下检查 1720px 桌面和 390px 手机的实际截图、导航图标、卡片对齐、视口适配及首页统计单次读取。没有执行长时间全量回归，也不宣称游戏客户端外观全部一致。

从 v0.6.2 升级没有依赖变更、数据库迁移、权限新增或私有素材重建；更早版本须先检查对应版本迁移要求。定向消息继续停用。使用同版源码和前端，按[部署指南](../DEPLOYMENT.md)操作并保留旧版本。
