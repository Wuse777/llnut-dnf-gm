## 采集及状态含义

root只读监控程序在已有15秒周期内，对PVF同目录下的固定 `frida.js` 进行有界读取，最多256KiB；拒绝符号链接、非普通文件与读取中变化。只输出格式版本、可读状态和SHA-256，不保存文件正文、连接配置、地址或凭据。采集失败不改变核心服务健康判定。

- **磁盘脚本已匹配：** 新鲜快照中的SHA与已核对版本一致，可以显示该版本的启动配置。
- **脚本版本变化：** 仅显示新SHA，不沿用旧版本的配置列表。
- **采集未知／过期：** 不显示旧SHA或旧启动配置，不能当作插件关闭。
- **运行中加载状态未核验：** 磁盘文件一致不能证明游戏进程已经加载或执行；不会显示「已生效」。
