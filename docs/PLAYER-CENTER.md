# 玩家与角色中心

## 新版紧凑交互（2026-11-06，仓库已实现／尚未部署）

最近／常用目标默认收起，展开后继续支持收藏和分页，选中即收起；错误和重试不随折叠隐藏。角色详情保留“调整所属账号余额／给此角色发奖励”，其余解锁和账号处罚入口放入“更多操作”；原有目标和未决操作校验不变。邮件页先选收件人；窄屏可直接在选物和奖励草稿间切换，金币或账号货币无需先穿过物品列表。字段错误自动展开并定位；详见[报告](reports/COMPACT-WORKFLOWS-20261106.md)。下文所述能力和数据语义保持不变。

## 当前角色详情导航（2026-11-06）

角色身份区由头像、可收缩的姓名／账号信息和状态组组成；手机把登录与删除状态放在同一可换行区域，减少固定身份区高度，保留完整目标和职业插画出处。

角色详情按「角色资料／装备与仓储／维护与排查／邮件与记录」分组。桌面只展示当前分组子页签，切回分组恢复该组最近查看页面；手机使用分类选择器。方向键、Home／End仍可切换内容。维护预览和结果保留在原面板，切换分类不等于取消操作；有未决操作时快捷跳转仍要求先处理。版本与上线情况以实施台账为准。


在「账号与角色」按账号/UID或角色名/编号查找。账号详情可查看旗下角色、该玩家邮件及账号审计。

## 角色详情

- 桌面通过分类标签切换，手机通过「查看内容」下拉框切换；存档说明默认折叠，可随时展开。
- 顶部快捷入口：调整所属账号余额、给当前角色发奖励、查看解锁、封禁/解封所属账号。携带UID/角色编号进入草稿，不自动充值或发送。最终确认仍展示收件人。
- 「角色邮件」固定为当前UID和角色编号，完整附件分页、领取/删除标记及缺失记录含义与独立邮件中心一致。复制操作仅建立新草稿。
- 「管理记录」列出明确关联本角色的记录；可勾选显示没有绑定角色编号的账号记录，带有独立标签。不会把其他角色专属记录列作当前角色记录。
- 管理记录使用游标分页，每次最多检查100条该账号记录、返回20条匹配项。稀疏匹配的空页可能仍有更早数据，按页面提示继续翻页。
- 维护/解锁有未完成预览或待确认结果时，快捷写操作跳转不可覆盖原上下文；先处理原操作。角色被删除或归属缺失时不创建写入草稿。

所有展示均为存档/管理记录，不代表实时战斗面板或游戏客户端已收到奖励。

## 最近访问与常用目标（015）

「账号与角色」「邮件发放」顶部新增玩家快捷目标，按账号或具体角色保存。选择账号／打开未删除角色详情会记录最近访问；星标或「收藏当前账号／角色」保存常用目标，12项分页。元数据保存在管理库，可在其他浏览器登录后读取，没有新权限开关或账号范围限制。不会保存草稿、自动充值或发奖。

每次展示重新查询当前名称与归属；账号／角色缺失、角色删除或归属变化时卡片不可用，但可以取消收藏。打开仍走原账号、角色查询，最终写操作保留原预览确认及校验。收藏只改变界面偏好，不生成业务审计或奖励流水；需要登录、CSRF/Origin及限速。

同一登录会话内，跨工作区返回保留搜索、分页、滚动位置，以及每个账号的角色／邮件／历史视图。退出登录会清理页面状态；收藏和最近访问仍保存在管理库。角色详情固定展示姓名、账号、等级与登录表状态（不是实时会话证明）。

邮件数据库提交后，可直接查看该操作的完整邮件／附件记录；「继续给此角色发放（新草稿）」保留目标、清空旧奖励与原因，不复用确认或自动重发。

升级：应用健康检查要求015；运行用户仅新增 `player_preferences` 的SELECT及必要INSERT/UPDATE列权限，不增加游戏库权限。回滚保留015表与收藏；旧应用仍按1–14查询，不因多出的015停止工作。
