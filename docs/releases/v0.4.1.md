# v0.4.1 · 匹配客户端图标与图片覆盖预览

2026-11-08 · llnut/dnf 清风1031／MySQL 5.7 专用适配版

本版用维护者提供的匹配客户端验证真实物品图片链路，并修复离线解析器兼容问题。公开包包含解析、索引与显示代码；游戏图片需部署者自行准备，不随开源源码或附件分发。

## 变化

- **真实素材验证**：1,585 个 NPK 目录可读；66,456 项物品中 66,450 项图标可解析，去重为 29,195 张 PNG。剩余 3 项缺客户端成员、1 项无 PVF 引用、2 项引用帧越界，继续明确显示缺图状态。该覆盖率只针对本次匹配样本。
- **正常图标不再被未使用帧阻断**：同一 IMG 中未选中帧的越界放置不会连带拒绝正常帧；当前帧与链接目标仍检查画布，全部帧仍检查尺寸、载荷范围和解压预算。
- **覆盖页可直接看图**：管理员可在图片状态明细查看鉴权缩略图、名称及编号；展示剩余缺口数，高覆盖率不会四舍五入误报为 100%。
- **Windows 离线构建**：头像映射 JSON 明确按 UTF-8 读取，支持中文路径与来源说明。现有 11 职业宣传插画可通过新包合并工具保留。
- **发布说明标题**：发布脚本从对应版本说明读取标题，不再沿用上一版本的固定标题。

## 下载与升级

| 附件 | 内容 |
| --- | --- |
| `llnut-dnf-gm-0.4.1-source.tar.gz` | 固定标签源码与文档 |
| `llnut-dnf-gm-0.4.1-web.tar.gz` | 同版 `web/dist/` 与 `SOURCE_REVISION` |
| `SHA256SUMS` | 两个附件的 SHA-256 校验值 |

附件不包含游戏服务端、客户端、PVF、NPK、真实 PNG、派生索引、私有配置、凭据或玩家数据，也不是完整离线安装包。构建环境为 Python 3.12、Node.js 24.15+ 的 24.x；安装与升级继续遵循[部署指南](https://github.com/Wuse777/llnut-dnf-gm/blob/v0.4.1/docs/DEPLOYMENT.md)。

从 v0.4.0 升级没有新管理库迁移或数据库授权。旧图片包不会因升级解析器自动增加图标；请在维护电脑用匹配 PVF、索引及客户端生成**新目录**，保留旧包，核对后设置 `assets_dir`。头像合并、目录权限、安装与回滚见[图片指南](https://github.com/Wuse777/llnut-dnf-gm/blob/v0.4.1/docs/ASSETS.md)。

## 验证与边界

本批定向检查覆盖离线解码、所选／未选帧、链接、载荷边界、私有包合并、只读图片服务及覆盖缩略图；前端验证图片显示、地址约束、缺口提示与类型检查／构建。完整结果及私有实例安装状态见[本批报告](https://github.com/Wuse777/llnut-dnf-gm/blob/v0.4.1/docs/reports/CLIENT-ASSETS-20261108.md)。未运行全量游戏业务回归，不通过测试写入生产玩家存档。

PVF 指纹一致、图片可解析和浏览器可显示不等于逐项游戏客户端视觉验收，`client_verified` 保持 false。现有职业宣传插画不冒充像素职业头像或角色实际装备外观；纸娃娃、可靠指定玩家系统消息等仍待开发。
