# 转职／觉醒关联维护

角色详情 → **维护与排查 → 转职与觉醒**。在同一基础职业内选择当前PVF支持的转职分支、未觉醒／一觉／二觉；支持退回较早阶段，不提供跨基础职业或性别转换。

## 网页操作

1. 在「功能与版本」开启「转职／觉醒维护」；唯一管理员可网页管理，不需SSH修改权限，也没有测试账号限制。
2. 查看当前职业、等级和目标列表。列表名称来自PVF各分支的觉醒段；原文件缺少名称时如实标注，不套用其他分支名字。
3. 在维护中心显式开启维护窗口。仅查询不会停止游戏；开窗及恢复是管理员主动操作。
4. 选目标、填原因，预览职业、成长属性和两套技能前后差异，核对后确认。
5. 如响应中断，按原编号查询，不自动重复提交。完成后关闭维护窗口，由游戏重新加载存档。

## 联动范围

- 修改成长类型，保留独立高位标记及基础职业、性别、等级、两处经验。
- 按同等级原／目标职业成长基线差额调整已适配属性及四系抗性，保留额外非成长加成。
- 重建两套PvE技能树，关联初始／转职／当前觉醒／副职业赠送技能和基础SP／TP；有效临时洗点备份同步重建。人工额外赠点不保留，预览中明确提示。
- 保留任务进度、QP、装备、指令、付费权益、公平决斗存档；不模拟原生转职任务、活动奖励、公会或网络事件。

这是**存档维护**，不是游戏在线原生转职。任务／QP和装备被保留并不表示适合目标分支，管理员应按实际玩法决定是否另行调整。不以数据库提交成功冒充客户端效果验证。

## 索引与授权

索引绑定当前PVF和清风1031原生程序指纹，在维护电脑本地生成新的副本：

```bash
PYTHONPATH=src .venv/bin/python tools/enrich_catalog_professions.py \
  /private/catalog-with-growth-and-skills.sqlite /private/Script.pvf \
  /private/catalog-professions-new.sqlite
```

新工具保留已有物品、策略、附魔、任务、成长与技能表，仅添加职业显示规则及两个版本元数据。安装前逐表核对，原子替换，保留旧索引；实际索引与PVF不进入公开仓库。

专用运行用户仅新增 `charac_info.grow_type` 列UPDATE；成长／技能依赖沿用相关模块列授权，不授予基础职业、性别或整表UPDATE。所有预览、执行、快照、幂等意向与审计复用同连接事务及维护许可。当前存档或规则变化后旧预览不可继续执行。

## 最小验证

- 两项纯规则测试：分支名称、独立高位、成长差额与额外属性保留。
- 两项本地MySQL5.7合成数据测试：两套技能／成长原子提交、重复确认、快照与审计、变更拒绝和回滚。
- 一项前端测试：选择、就地错误、关联预览、响应丢失后不重发。
- 构建及公网只读冒烟；生产不自动开维护窗口、不修改玩家存档来测试。
