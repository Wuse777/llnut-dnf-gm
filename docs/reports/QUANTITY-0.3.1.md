# 0.3.1 发放数量调整验证

日期：2026-11-04。基于0.3.0 / 026952f，不包含游戏资源、玩家数据或生产凭据。

## 行为

- 已知上限、未知上限、0和负数PVF堆叠元数据均不再限制发放数量；`indexed_stack_limit`保留原值。
- 邮件、礼包、预览和确认统一只检查1–2,147,483,647正整数，这是既有`postal.add_info`有符号INT表示范围，不是新的PVF或策略限额。
- 装备、时装、宠物和宠物装备可填多件，按件产生原生投递记录；普通道具直接写数量。金币只在第一条附件携带一次。
- 每次仍可组合20项物品配置；逐件展开的投递记录可超过20条。结果保存总数和前20个真实邮件附件ID，并明确标记截断，不静默少发。
- 旧`mail_stack_limits`兼容键不再生效。认证、预览确认、幂等、审计、PVF指纹及管理员手动停用行为不变。
