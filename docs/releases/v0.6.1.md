# v0.6.1 · SoybeanAdmin 工作台与角色外观管线

发布日期：2026-11-09。

本版为首个可下载的 SoybeanAdmin 重构发行版。保留已推送的 v0.6.0 源码标签，修复其干净检出缺少公开 Vite 环境默认值导致发布构建失败的问题；公开默认值随源码分发，私有覆盖仍使用忽略的 `.env.local`。

将前端迁入固定版本 SoybeanAdmin v2.3.0，采用 Naive UI、Pinia、路由、工作页签和浅色蓝紫主题。DNF GM 继续维护自己的版本号，保留 Python 后端与 `/dnf-gm/` 地址。新增地下城徽记、阿拉德背景字样及受鉴权的职业插画背景；原始游戏素材不随开源附件分发。

## GM 工作流

- 导航按工作台、玩家中心、奖励运营、道具与外观、系统运维组织；首页优先玩家搜索、最近与收藏目标、待处理问题和原操作查询。
- 账号和角色具有独立地址，可直接访问；角色内容分为概览、装备与仓储、外观与动作、成长与技能、任务与救援、奖励与邮件、管理记录。
- 多玩家页签与奖励草稿绑定 UID／角色；刷新恢复按管理员会话隔离。PVF 改变后清理旧物品绑定，退出清理会话草稿；关闭页签不删除原操作编号。
- 保留 Cookie、CSRF、服务端预览、过期检查、重新认证、幂等与维护屏障；普通奖励、原生控制、库存和维护共用一份确认展示租约。超时或恢复页面不自动重发写入。
- 物品目录、邮件、礼包与批量奖励共用选物与筛选语义，增加已核实的职业适用、武器类别和套装元数据；未知字段显示未收录。保留最多四件对比，不生成战斗力评分。
- 常用筛选、网页外观方案和布局偏好存入管理库，按 PVF 隔离并使用版本号处理冲突；兼容导入原浏览器常用筛选。网页试穿仅生成预览，不直接写角色装备。

## 私有外观素材

新增版本化部件、独立图集和 ANI 时间线，浏览器 Canvas 按固定锚点合成静态帧与基础动作；可选择动作、暂停、调速和左向镜像。后台及离开页面自动暂停，同时只运行一个人物预览。

透明时装按当前实例关联解析，拒绝悬空、重复、嵌套或跨角色替代。已核实部件可部分展示，未绘制的光环、发光混色层、染色或职业附加层必须列出原因，不能标为完整还原。新增 **32 个有来源证据的客户端转职插画映射**，另保留 11 个基础职业示意；独立觉醒插画覆盖为 0，觉醒角色使用同转职示意时明确说明。[头像证据](../PORTRAIT-EVIDENCE.md)可单独审查。

画布上限 512×512，图集页上限 2048×2048，活动解码缓存上限 64 MiB；不支持或超预算回退静态展示。旧图标与首帧素材包保持兼容。详见[外观指南](../CHARACTER-APPEARANCE.md)和[工作台指南](../UI-WORKSPACE.md)。

本轮私有样本包含 129 个显式物品、729 条部件动作和 387 张图集；六个只读存档配方均可绘制待机／行走，其中两套有已支持的站立普攻片段。六套均为部分还原，具体武器及特殊层差异见[覆盖矩阵](../APPEARANCE-V2.md)。数字不代表整个客户端全部搭配覆盖。

## 升级与检查

本版增加管理库迁移 **017**。既有实例升级时需要对已核实的时装关联列 `user_items.ui_id` 增加只读权限，没有新增游戏表写权限。扩展职业／武器／套装筛选需离线更新目录元数据；新动作需安装匹配 PVF 的私有部件包。旧包继续工作，但不凭空获得动画和完整外观。

前端工具链固定为 Node.js 24.x、pnpm 12.10.1、Vite+ 1.1.0；上游版本、提交、适配点和 MIT 声明保留于 `web/UPSTREAM.json` 与 `web/SOYBEAN-LICENSE`。公开源码和网页附件均不含 PVF、NPK、真实索引、玩家数据或私有配置。

按用户偏好，以类型检查、生产构建和目标隔离／预览／结果未知等关键场景为本轮交付检查；没有将长时间全量回归设为发布前置，也不声称全量 CI 已通过。游戏客户端外观与动作一致性由部署者依据覆盖清单验收。

定向系统消息继续按用户安排保持生产停用。只更新独立 GM，保留旧程序、配置与私有素材目录以便回滚；不重启游戏或共享基础服务。安装与升级见[部署指南](../DEPLOYMENT.md)，版本化界面数据见[偏好接口说明](../UI-PREFERENCES.md)。
