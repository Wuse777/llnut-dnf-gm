## 更新规则

1. 使用当前源码、本地固定演示数据；不要登录生产后台拍图后仅靠遮挡密码。
2. 展示真实交互，不把假图标、伪造成功结果或设计稿当作已实现功能。
3. 检查账号、IP、路径、日志、密钥、玩家姓名及游戏图片均不泄露；保存 PNG／JPEG，控制体积。
4. 同步更新本文件、界面导览与首页文字；标注源码／合成数据／客户端效果的区别。
