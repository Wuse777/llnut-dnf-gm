# 装备修改前后身份与语义对照（2026-11-06）

## 功能与边界

新预览分别保存修改前后物品索引元数据，回收空槽位不再沿用原装备名称，恢复显示快照物品名／部位。仅新增展示元数据，没有更改存档修改算法、权限、维护窗口或数据库结构。既有旧预览若因新版元数据与重算不一致会拒绝确认，需取消后重新预览；不能为兼容旧预览绕过目标校验。已提交历史结果仍可读取。

卡片分项显示强化、锻造、数量、耐久、增幅代码／数值、附魔和品级原始值，修改后有明确文字变化标记。未知语义仍明确标为原始值，不伪装成品级百分比或已核实属性。图片仅在当前读取物品编号与该侧一致时复用；没有匹配图片时保留占位。图片和资源包状态不进入事务预览／确认比较。旧版历史没有该侧身份且编号不同时显示未知，不套用另一个物品名称。

桌面双栏／手机单栏，沿用现有CPAMC主题；不新增运行依赖、权限开关或迁移，不改变物品数量1–2,147,483,647及10亿邮件金币上限。

## 最小验证

3项无数据库预览测试，覆盖编辑／回收／恢复两侧身份；两个相关前端文件19项，覆盖名称、数值、缺图、历史回退和原有确认防重；类型检查与生产构建通过。仅本地合成角色与物品浏览器预览，桌面1280px／手机390px无横向溢出，无JS错误；不使用真实游戏素材夹具、不发生产维护预览、不写玩家存档。
