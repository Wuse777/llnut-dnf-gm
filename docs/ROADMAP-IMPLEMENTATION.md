## 邮件标题实现（2026-11-05）

单次邮件、模板版本、临时调整和批量奖励支持 `mail_title`；标题与正文分别存储在请求/模板中，游戏仍通过已适配的 `letter_text` 写入，标题作为首行。不是虚构的客户端独立标题栏。预览展示合并文本，邮件中心显示实际投递文本并保留独立草稿字段。无标题时保持原格式和旧定时绑定；不改变附件数量、金币规则或权限。

标题须为单行、最多40字符；标题/换行/正文合计最多255 UTF-8字节，对应当前文字字段的编码容量，超出在输入处提示，不截断。定向系统消息独立保持待适配，见 `NATIVE-MONITOR.md`。
