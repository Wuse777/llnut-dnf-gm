# v0.6.2 · 修复登录页和工作台样式

发布日期：2026-11-09。

修复 v0.6.1 在真实部署中登录页、导航和主页面排版异常的问题：后端仍使用旧版 `style-src 'self'`，浏览器因此拒绝 Naive UI 控件和 SoybeanAdmin 主题生成的动态样式。本地无该响应头的静态预览无法发现此差异。

本版为每次页面请求生成独立 style nonce，将同一个值写入 CSP 和入口 meta。锁定版本的 css-render 使用受控补丁，仅为其自身创建的 style 节点传递该值；主题样式同步传递，Naive 开启 `inline-theme-disabled`。保留 `script-src 'self'`，没有加入 `unsafe-inline`／`unsafe-eval`，也没有为任意新增 style 节点自动授权。

旧 GM 表单样式在 Naive 控件边界停止，避免覆盖输入框和按钮。登录页使用可收缩网格，960px 以下改为单列，修复双重卡片内边距，并补齐独立的浅色／暗色文本变量。

验证包含 18 个后端无数据库策略与静态入口检查、组件和主题 nonce 传递检查、类型检查及生产构建。浏览器检查工具因无法可靠确认当前 URL 而中止，本版不声称完成全部真实浏览器布局验收。上线后另检查实际 HTTPS 响应头、入口 nonce、脚本/CSS 和只读健康接口。

此补丁不迁移数据库、不更新私有素材与目录库，不改变奖励和游戏写入流程；定向消息仍停用。升级必须使用同版后端与前端，不能将新前端单独配给旧后端；反向代理如额外配置 CSP，须避免叠加冲突策略。发布文件和升级方法见[部署指南](../DEPLOYMENT.md)。
