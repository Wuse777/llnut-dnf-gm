# 第二十三批：网页权限、功能与版本中心

日期：2026-11-05。状态：本地实现，未推送、未部署。

## 对齐最新要求

最终安装对唯一管理员初始化全部已实现开关、解除测试UID限制；之后从网页启停，不要求用户通过SSH编辑功能权限。保留密码重新认证、Origin/CSRF、防重、事务和存档冲突保护，不将缺少人工验收记录当成额外授权门槛。未实现的原生协议仍明确标注，不伪装可用。

## 实现

- 新增“功能与版本”：源码、管理库001–012、PVF/镜像、物品索引/图片包、快照时间、开关与可选人工验收记录分别呈现。缺失、过期、脏版本不继承正常或验收结论。
- 16个固定开关在网页选择、核对、保存。依赖联动提前体现在勾选和确认差异里；“全部开放”仅选择，不发送游戏指令。开启执行器可能继续已授权任务，界面明确提醒。
- 012管理库持久策略与原请求收据；修订冲突保护、同编号同参数防重、不同参数拒绝；设置、收据、成功审计同MySQL事务。仅复用现有单执行器及最多3连接，无新增队列/游戏表结构变更。
- 当前进程动态读取策略，不重启服务；数据库策略未知时暂停新受控写入，仍能登录、只读和查原结果。重启/重复安装保留管理员后续选择。
- 提交响应丢失保留原编号，刷新后只GET核对；隐藏页暂停轮询，不自动重发。审计可以通过通用操作编号入口读取权限收据，但不能通过游戏确认接口再次执行。
- 升级脚本完成012、专用权限及已实现装备功能的固定列权限；只在修订0初始化全部开放。旧代码不识别网页策略时拒绝回滚，保留审计/任务/权限。
- 新页沿用CPAMC主题变量、手机双列开关、就近错误和嵌套确认框。不是最终整站美化完成。截图复核同时修正旧全局说明，不再错误声称已经实现的存档回收完全不存在。
