# v0.5.0 · 组合选物、装备视图与运维验证

发布日期：2026-11-09。

本版将物品筛选、对比与穿戴槽位放到同一工作流，减少手机长页和首次脚本加载；补充管理库隔离恢复演练、独立定向系统消息桥及 CI 引导／已定位回归修复。公开附件只包含源码和静态网页，不包含游戏素材或玩家数据。

## 选物与角色

- 名称／编号、类型、发放状态、部位、PVF 原始品级和等级范围组合筛选，支持等级／名称排序及按 PVF 分开的本浏览器常用条件。
- 最多四件物品并排比较部位、等级、耐久和 PVF 顶层定义原值；排除显式成对段，遇到交错或未闭合条件段时不展示属性，不计算条件或附魔。旧属性索引须离线重新生成，不把原值当作实际战斗属性。批量发放策略继续覆盖完整筛选结果，筛选条件绑定预览和确认。
- 穿戴视图按 12 个真实存档槽位排列，未知扩展槽仍可见；物品图标、品级边框和详情保持统一。
- 可选离线生成 11 个基础职业默认站姿；默认预览清楚标注来源，不冒充当前时装、武器、精确觉醒阶段或客户端效果验收。
- 新增已核实穿戴区域的时装存档只读查询、规范配方摘要及当前 PVF／基础职业／配方精确图片查询。透明替代、染色、部位未知或重复时整份拒绝；本批真实抽查可用完整配方为 0，生产包只有 11 个默认站姿，不含 5 个离线测试配方。完整纸娃娃与精确觉醒头像仍未完成，见[外观指南](../CHARACTER-APPEARANCE.md)。
- 职业插画默认收起，手机可横滑与键盘切换；角色和运营面板按需加载，较重面板加载失败可重试。

## 运维与定向消息

- `management_backup.py rehearse-latest` 严格选择最新完整管理库快照，在 socket-only 隔离 MySQL 中恢复、核对表定义／内容并清理；历史演练证据不因后续备份而被覆盖，也不会冒充最新文件已经恢复验证。
- 新增限定 UID＋角色编号的系统消息操作，复用原因、重新认证、预览、一次确认、持久派发占位和审计。发送后只报告桥接调用结果，响应不确定时禁止自动重发。
- 独立 root relay 使用 Unix socket、对端凭据、程序／脚本指纹和固定命令；游戏主线程重新解析在线角色并核对归属，既不保存跨请求角色指针，也不开放任意代码或原始封包入口。
- **定向消息本批按用户安排暂不启用**。现有游戏脚本热重载会重复初始化钩子、数据库和活动排程，不能随 GM 网页升级直接加载。未来需按[定向消息安装指南](../PRIVATE-MESSAGE.md)，在维护窗口加载独立桥，再用专用在线角色完成真实客户端验收。

## 验证与升级

全量验证、真实素材覆盖、恢复演练和部署结果分别记录在[本批报告](../reports/DEVELOPMENT-20261109.md)。合成测试、素材解码、桥接调用与游戏客户端效果分别陈述，不相互替代。

前端 422 项及类型检查／生产构建已通过。最近一次 Linux 全量使用修复前快照，结果为 2,028 通过、59 失败；已修复已定位原因，本次按用户要求不再等待新的全量回归，不能将本版记为全量 CI 已通过。

本版无管理库迁移，无依赖更新。时装只读接入需要对 `taiwan_cain_2nd.user_items` 增加 `SELECT(charac_no,slot,it_id,stat,expire_date,clear_avatar_id,color1,color2)` 的最小八列权限，没有新增游戏表写权限；新安装由授权工具提供，既有实例由升级维护补充。缺列／缺权限时仅服装区域不可用，其余角色信息继续可读。

组合部位／品级筛选需要离线补全装备索引；旧索引缺字段时明确拒绝相关筛选。新默认站姿为可选图片包扩展，旧包继续显示占位。定向消息需要额外安装且保持关闭，不会因更新源码自动启用。

升级前保留配置、旧程序与私有索引／图片目录；按[部署指南](../DEPLOYMENT.md)只替换 GM。源码包和网页包不是含 wheels 的完整离线安装包；安装后仍须检查就绪、素材鉴权和写入准入。
