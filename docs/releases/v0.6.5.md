# v0.6.5 · 减少切页等待与重复读取

版本日期：2026-11-09。本说明记录源码变更与针对性检查；生产部署状态另行确认。

页面默认立即切换，不再等待旧页面退出动画。已经保存的动画偏好保留为 100ms 的进入淡入；关闭动画、系统要求减少动态效果或浏览器不支持动画时立即展示。旧页面先移除再挂载新页面，避免切换期间重复表单与目标混用。

相同的在途只读查询复用同一请求，各读取方可独立取消。物品目录增加仅保存在当前页面进程内的 30 秒缓存，最多 12 项；完整查询条件、会话、PVF 和策略共同确定缓存范围。手动刷新可绕过缓存，写入后清理读取缓存；不会把私有查询结果保存到浏览器持久存储或公共 HTTP 缓存。新条件替换过期读取，旧会话的迟到响应不能重新填充当前界面。

玩家检索、选物、记录和结果查询使用对应区域的加载提示，读取期间仍可操作其他无关区域。提交写入与变更目标所需的锁定保持原有约束。未决操作继续保存和查询原操作编号；刷新、重新认证及查询取消不会自动重放写请求，结果待核对也不生成新的发放编号。

本轮 12 个文件、77 项前端聚焦测试、类型检查、生产构建和文档检查通过，覆盖只读请求合并与取消、缓存隔离、玩家读取、选物查询、路由切换、会话失效及未决操作恢复。真实 Chrome 配合生产 Guard／CSP 和本地合成 API，检查目录返回复用、手动刷新、慢搜索替换、角色切换后的独立草稿与 URL 恢复，以及 390px 手机布局；未发现页面错误、外部请求或 CSP 违规，没有提交游戏写操作。未运行长时间全量回归，也没有据此给出真实 API 延迟改善比例、线上无 503 或游戏客户端验收结论。

首页继续展示 [v0.6.4 的合成数据截图](../SCREENSHOTS.md)，保留其版本与来源说明；本版没有把历史截图重新标注为新版本实测。

从 v0.6.4 升级无需数据库迁移、额外游戏读取授权、私有素材重建或资源配额调整。会话 Cookie、CSRF、预览有效期、重新认证、幂等提交及审计沿用；定向消息继续停用。按[部署指南](../DEPLOYMENT.md)配套更新同版源码和前端，并保留旧版本用于回滚。
