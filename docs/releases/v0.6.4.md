# v0.6.4 · 整理登录与选物布局，精简首屏 SVG

版本日期：2026-11-09。本说明记录源码变更与本地针对性检查；生产部署状态另行确认。

登录页采用居中、桌面最大宽度约 1000px 的整体双栏卡片，品牌介绍和登录表单放在同一个容器，减少两个面板分别悬空、上下错位的问题；手机保留单列登录表单。继续使用 v0.6.3 的原创天空城背景。

同时修正对当前 Naive UI 内部类名的选择：旧的 `n-card__content`、`n-button__content` 与已固定的组件版本不匹配，导致部分内容间距和按钮排列规则未生效。更新选择器后恢复卡片内距与常用入口对齐。

最近与收藏目标增加 40px 离线身份图标，用于区分账号和角色，不将它标为精确职业头像。统一选物支持图标网格和紧凑列表，视图偏好按 PVF 版本保存在本机浏览器，不修改服务端冻结的奖励筛选条件。角色概览增加静态人物侧栏，手机可折叠；实际存档、默认示意、网页试穿和缺失部件继续分别说明。

物品目录及奖励编辑器加入原创公会补给台短横幅，通过对应业务路由加载。桌面 WebP 为 1672×941、182,514 字节；手机 WebP 为 800×450、48,782 字节。场景中的武器、卷轴和包裹只是装饰，不是可选择的真实游戏物品。生成提示词及来源见[背景素材说明](../design/BACKGROUND-ART.md)。必要的游戏物品图标、职业插画和人物素材保留原私有鉴权链路，不随公开 Release 分发。

本地 SVG sprite 原先在每次进入页面时注入 18 个 symbol、368,104 字节，包含当前 GM 页面未使用的模板插画。现在仅注册实际需要的 `no-icon` 兜底 symbol，编译内容为 8,927 字节，减少 97.6%；未知的旧页签图标回退到该 symbol。静态图标仍支持构建时按需编译，离线界面图标保持可用。

旧 sprite 含 169 个内联 `style` 属性，是本轮页面检查记录的 `style-src-attr` 违规来源；编译时将样式转为 SVG 属性，并拒绝残留的内联样式。新的 sprite 中该项为 0。保留现有 CSP 和样式 nonce，不加入 `unsafe-inline` 或放宽脚本策略。这一结果针对本地 sprite，不代表所有业务页面已完成 CSP 检查。

最终生产构建的主入口从 v0.6.3 的 563,656 字节降到 206,742 字节，gzip 体积从 157,762 字节降到 55,420 字节。这里比较的是主入口文件，不是全部路由、预加载依赖或图片的总下载量；体积减少不能等同于实际网络或交互耗时已经改善。

本轮检查：7 个文件、48 项前端聚焦测试通过，覆盖工作区、角色详情、最近目标、奖励编辑器、sprite／离线图标和 nonce；类型检查、生产构建及文档检查通过。真实 Chrome 配合生产 Guard／CSP 与本地合成 API，检查了 1720px 桌面和 390px 手机的登录页、工作台、目录紧凑列表、角色概览及奖励横幅。检查期间 CSP 事件为 0、页面运行错误为 0、外部请求为 0、横向溢出为 0；桌面登录双栏共用边线并居中，手机角色人物区默认折叠。最新[公开截图](../SCREENSHOTS.md)使用同一合成数据流程，不包含游戏素材。

未执行长时间全量回归；上述检查不代表生产部署、线上无 503、全部游戏客户端外观或实际响应耗时已经验证。

从 v0.6.3 升级无需数据库迁移、额外游戏读取授权或私有素材重建。会话、CSRF、预览确认、重新认证与幂等提交协议沿用；定向消息继续停用。按[部署指南](../DEPLOYMENT.md)使用同版源码和前端，并保留旧版本用于回滚。
